== Processamento de Imagens Coloridas

:toc: left

* Agora vamos explorar o processamento de imagens coloridas utilizando o OpenCV. Iniciamos aplicando diferentes mapas de cores (colormaps) a uma imagem colorida, seguida pela conversão entre diferentes modelos de cor, como RGB e HSV. Utilizamos funções como applyColorMap() para aplicar colormaps predefinidos e convertTo() para manipular os canais de cor individualmente. Além disso, demonstramos a conversão entre os espaços de cor RGB e HSV usando cvtColor(), permitindo uma análise detalhada dos componentes de cor em diferentes representações.

=== Mapas de Cores
* Este programa aplica diferentes mapas de cores a uma imagem colorida utilizando a função applyColorMap do OpenCV. Inicialmente, a imagem "teozin.jpg" é carregada e convertida para escala de cinza. Em seguida, são aplicados diversos mapas de cores predefinidos, como COLORMAP_JET, COLORMAP_HOT, COLORMAP_COOL. Em seguida, cria uma tabela de lookup (LUT) personalizada onde o canal azul (B) é crescente, o verde (G) é decrescente e o vermelho (R) permanece zero. Aplica essas LUTs separadamente na imagem original e combina os três canais resultantes usando merge() para formar uma imagem colorida final.

=== Modelos de Cor
* Agora utilizaremos a imagem RGB.jpg para demonstrar a conversão entre diferentes modelos de cor utilizando o OpenCV. Aplicando diferentes colormaps pré-definidos sobre a imagem original e, para cada resultado, realizando a separação dos canais de cores usando a função split(). Em seguida, converte cada imagem com colormap aplicado para o espaço de cores HSV, onde novamente utiliza split() para decompor e analisar separadamente os componentes de Matiz (H), Saturação (S) e Valor (V), permitindo uma visualização detalhada das características cromáticas em diferentes espaços de cor.
