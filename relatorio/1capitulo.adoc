=== Conceitos Iniciais
* O objetivo do programa é utilizar o arquivo "teozin.jpg" com o objetivo de calcular o negativo de uma área retangular definida pelo usuário. Para isso, a imagem é convertida para escala de cinza com imread(GREYSCALE) e são criados dois pontos P1 e P2 usando a estrutura Point do OpenCV. Através de um loop for duplo que percorre a região entre esses pontos, subtrai-se o valor máximo (255) de cada pixel, gerando assim o negativo apenas na área delimitada pelo retângulo.

=== Manipulando pixels em uma imagem

* Este programa utiliza o arquivo "teozin.jpg" para realizar uma permutação dos quadrantes da imagem. A imagem é carregada em escala de cinza e suas dimensões são divididas ao meio para obter quatro regiões iguais (A, B, C, D). Através de um clone da imagem original e um loop for duplo que percorre metade das linhas e colunas, é executada a troca das posições: o quadrante A é trocado com D, e o quadrante B é trocado com C, resultando em uma reorganização espacial dos quadrantes na configuração final D C B A. A imagem modificada é então exibida em uma janela até que qualquer tecla seja pressionada.

=== Tratando arquivos de vídeo

* Este programa processa um arquivo de vídeo passado como argumento para criar uma versão modificada em negativo e escala de cinza. Utilizando VideoCapture para leitura do arquivo original e VideoWriter para gravação do resultado, o vídeo mantém suas dimensões originais especificadas em frameSize. Cada frame é convertido para tons de cinza através de cvtColor() e sofre aplicação de negativo usando bitwise_not(), que inverte os valores dos pixels. Os frames processados são gravados continuamente no arquivo "output.avi" enquanto um contador registra o número total de frames processados até o final do vídeo original.

=== Visualização de Imagens

* Este programa utiliza o Gnuplot para gerar três representações visuais de imagens em tons de cinza. Para a visualização 3D, plota-se superfície onde as coordenadas X e Y representam a posição do pixel e Z a intensidade. O mapa de relevo é criado com pm3d, gerando uma projeção 2D com cores que indicam alturas. Já a representação matricial utiliza a matriz image para exibir os valores numéricos diretamente em formato de grid, onde cada célula corresponde a um pixel da imagem original.

Ele carrega a imagem "teozin.jpg", gera o arquivo "image.txt" com a matriz completa de intensidades dos pixels e "line.txt" com os valores da linha central. * O programa gera uma imagem senoidal e a armazena em formatos YAML e PNG. Primeiro, cria uma matriz 256x256 em ponto flutuante onde cada pixel recebe um valor calculado pela função seno com 4 períodos completos ao longo da largura da imagem. Os valores são salvos no arquivo YAML mantendo a precisão original em float. Para visualização, a imagem é normalizada para a faixa 0-255, convertida para 8 bits sem sinal e exportada como PNG.
