Processamento de Imagens no Domínio Espacial

  • Neste capítulo, exploramos técnicas de processamento de imagens no domínio espacial utilizando o OpenCV. Abordamos desde operações básicas como convolução 2D até efeitos visuais avançados como profundidade de campo e tilt-shift, aplicados tanto em imagens estáticas quanto em vídeos.

Convolução 2D

  • A ideia dessa prática é demonstrar os efeitos da convolução 2D com o filtro da média aplicado com kernels de diferentes dimensões. Utilizando a função cv::blur() do OpenCV, são aplicados filtros de média com kernels 3x3, 11x11 e 21x21 sobre a mesma imagem redimensionada. Conforme o tamanho do kernel aumenta, observa-se um efeito de suavização progressivamente mais intenso: o kernel 3x3 preserva a maioria dos detalhes enquanto reduz ruídos sutis, o 11x11 produz um desfoque moderado que elimina detalhes finos, e o 21x21 gera um borramento significativo onde apenas as características em larga escala da imagem permanecem visíveis, demonstrando claramente o trade-off entre redução de ruído e preservação de detalhes no processamento de imagens.

#include <iostream>
#include <opencv2/opencv.hpp>

int main(int argc, char** argv) {
    
    cv::Mat img = cv::imread(argv[1]);
    
    if (img.empty()) {
        std::cout << "Erro ao carregar a imgm: " << argv[1] << std::endl;
        return -1;
    }

    // Redimensiona para facilitar a visualização
    
    double fx = 0.5; // Scale factor for width (half the original width)
    double fy = 0.5; // Scale factor for height (half the original height)
    cv::resize(img, img, cv::Size(), fx, fy, cv::INTER_CUBIC);

    // tamanhos de kernel
    cv::Mat blur3x3, blur11x11, blur21x21;
    
    // Usando blur do OpenCV -> filtro de média
    cv::blur(img, blur3x3, cv::Size(3, 3));
    cv::blur(img, blur11x11, cv::Size(11, 11));
    cv::blur(img, blur21x21, cv::Size(21, 21));

    // Mostra os resultados
    cv::imshow("Original", img);
    cv::imshow("Media 3x3", blur3x3);
    cv::imshow("Media 11x11", blur11x11);
    cv::imshow("Media 21x21", blur21x21);

    cv::waitKey();//

    return 0;
}

Profundidade de Campo

  • A ideia dessa prática é implementar um algoritmo de profundidade de campo (Depth of Field) através do operador Laplaciano para detectar regiões de maior nitidez ao longo de um vídeo. Utilizando o filtro Laplaciano 3x3 [0,-1,0; -1,4,-1; 0,-1,0] com filter2D(), o programa calcula para cada frame o valor absoluto do Laplaciano, que indica as regiões de alta frequência espacial (bordas nítidas). A cada frame, é criada uma máscara binária comparando o Laplaciano atual com o máximo acumulado, e apenas os pixels mais nítidos são copiados para a imagem final de saída através do método copyTo() com máscara, resultando numa composição que acumula progressivamente as regiões mais focadas de todos os frames processados do vídeo.

#include <iostream>
#include <opencv2/opencv.hpp>

int main(int argc, char** argv) {
    cv::VideoCapture cap(argv[1]);
    cv::Mat frame, img_laplac;
    cv::Mat maxLaplacian, output;
    
    float laplacian[] = {0, -1, 0, 
                        -1, 4, -1, 
                         0, -1, 0};
                         
    cv::Mat maskLaplac(3, 3, CV_32F, laplacian);

    bool firstFrame = true;

    while (true) {
        cap >> frame;
        if (frame.empty()) break;

        cv::cvtColor(frame, frame, cv::COLOR_BGR2GRAY);
        cv::resize(frame, frame, cv::Size(frame.cols/2, frame.rows/2));

        cv::filter2D(frame, 
                     img_laplac, // output
                     CV_32F,          // float para evitar overflow
                     maskLaplac);  // aplicar o filtro laplaciano definido antes
        //valor absoluto do laplaciano pq pode dar negativo
        //então pegamos as bordas como positivas para ter mais nitidez
        img_laplac = cv::abs(img_laplac);  

        if (firstFrame) {
            maxLaplacian = img_laplac.clone();
            output = frame.clone();
            firstFrame = false;
        }

// ------------------ ALGORITMO DE DEPTH OF FIELD ------------------
        //máscara onde o frame atual é mais nítido
        cv::Mat mask_nitidez = img_laplac > maxLaplacian;
        
        // Copia para maxLaplacian apenas as regiões mais nítidas
        //Copia apenas os pixels de lapacianResult para maxLaplacian quando mask é diferente de zero
        img_laplac.copyTo(maxLaplacian, mask_nitidez);
        /*img_laplac -> se img atual mais nitida substitui o valor em maxlaplacian
        mask_nitidez determina quais posições os pixels estão mais nitidos*/
    
        frame.copyTo(output, mask_nitidez);// pegamos o valor de frame onde a máscara é verdadeira


        cv::imshow("Original", frame);
        cv::imshow("DOF", output);

        
    }
    std::cout << "Fim do vídeo" << std::endl;
    cv::imwrite("final_dof.png", output);
    cap.release();
    cv::waitKey();
    return 0;
}

Tilt-Shift

  • Este código cria um efeito tilt-shift que deixa apenas uma faixa da imagem nítida, como se fosse uma miniatura. A imagem original é desfocada com um filtro Gaussiano e depois combinada com a versão nítida usando uma máscara suave. A máscara é feita com funções matemáticas que criam uma transição gradual entre a parte focada e a desfocada.

Figure 7. Imagem antes do tilt-shift

  • Quatro controles deslizantes permitem ajustar o efeito em tempo real: um controla a altura da faixa em foco, outro regula a suavidade das bordas, outro move a faixa verticalmente e o último ajusta a intensidade das cores. A saturação é modificada convertendo a imagem para o formato HSV e alterando apenas o canal de cor, sem mexer no brilho.

#include <opencv2/opencv.hpp>

using namespace cv;
using namespace std;

// Variáveis globais
Mat image, blurred, result;
int altura, largura;

// Parâmetros iniciais
int slider_altura = 50;
int slider_decaimento = 50;
int slider_centro = 50;
int slider_saturacao = 50;  // Valor de saturação inicial (0-100)


//---------------------------------------------FUNÇÃO TILTSHIFT---------------------------------------------
void tiltshift(int, void*) {
    // Obter valores atuais das trackbars
    slider_altura = getTrackbarPos("Altura Foco", "Tiltshift");
    slider_decaimento = getTrackbarPos("Suavização", "Tiltshift");
    slider_centro = getTrackbarPos("Centro", "Tiltshift");
    slider_saturacao = getTrackbarPos("Saturação", "Tiltshift");
    
    // Calcular parâmetros
    float centro = slider_centro * altura / 100.0;
    float faixa_altura = slider_altura * altura / 100.0;
    float decaimento = max(0.1f, slider_decaimento / 10.0f);
    
    float l1 = centro - faixa_altura/2;
    float l2 = centro + faixa_altura/2;
    
    // Criar máscara
    Mat mask(altura, largura, CV_32FC1);
    // equação da máscara usando tangente hiperbólica
    for(int i = 0; i < altura; i++) {
        float fx = 0.5 * (tanh((i - l1)/decaimento) - tanh((i - l2)/decaimento));
        //
        for(int j = 0; j < largura; j++) {
            mask.at<float>(i, j) = fx;
        }
    }
    
    // MÁSCARA PARA DEBUG
    Mat mask_display;
    mask.convertTo(mask_display, CV_8UC1, 255.0);
    imshow("Máscara TiltShift", mask_display);
    
    Mat resultado1, resultado2;// resultados parciais
    // converter a imagem e seu borrão para float
    Mat image_f, blurred_f;
    image.convertTo(image_f, CV_32FC3);
    blurred.convertTo(blurred_f, CV_32FC3);

    //seperando os canais da imagem original
    // Separar os canais da imagem original e da borrada
    vector<Mat> canais(3);
    vector<Mat> blurred_canais(3);
    vector<Mat> resultado_canais(3);

    split(image_f, canais);
    split(blurred_f, blurred_canais);

    // Aplicar a máscara a cada canal
    for (int i = 0; i < 3; i++) {
        Mat parte_nitida, parte_borrada;
        multiply(canais[i], mask, parte_nitida);           // parte nítida (área em foco)
        multiply(blurred_canais[i], 1.0 - mask, parte_borrada); // parte borrada (fora de foco)
        add(parte_nitida, parte_borrada, resultado_canais[i]);
    }

    // Reunir os 3 canais de volta
    Mat resultado_float;
    merge(resultado_canais, resultado_float);
        
    resultado_float.convertTo(result, CV_8UC3);
    
    // APLICAR AJUSTE DE SATURAÇÃO
    if(slider_saturacao != 50) {  
        Mat hsv;
        cvtColor(result, hsv, COLOR_BGR2HSV);// Converter para HSV
        
        vector<Mat> canais;
        split(hsv, canais);// o canal 1 é o da saturação
        
        // Calcular fator de saturação: 0.5x a 2.0x
        float fator = slider_saturacao / 50.0f;
        canais[1] = canais[1] * fator;//multiplicar o canal de saturação
        // Garantir que valores não ultrapassem 255
        min(canais[1], 255, canais[1]);//truncando
        
        merge(canais, hsv);
        cvtColor(hsv, result, COLOR_HSV2BGR);
    }
    
    imshow("Tiltshift", result);
}

//-----------------------------------------------MAIN-------------------------------------------------
int main(int argc, char** argv) {
    if (argc != 2) {
        cout << "Uso: " << argv[0] << " <imagem>" << endl;
        return -1;
    }

    image = imread(argv[1], IMREAD_COLOR);
    if (image.empty()) {
        cout << "Erro ao carregar imagem!" << endl;
        return -1;
    }

    altura = image.rows;
    largura = image.cols;
    

    // Criar versão borrada
    GaussianBlur(image, blurred, Size(15, 15), 0);

    namedWindow("Tiltshift", WINDOW_AUTOSIZE);
    namedWindow("Máscara TiltShift", WINDOW_AUTOSIZE); // Janela da máscara

    // Criar as barras
    createTrackbar("Altura Foco", "Tiltshift", &slider_altura, 100, tiltshift);
    createTrackbar("Suavização", "Tiltshift", &slider_decaimento, 100, tiltshift);
    createTrackbar("Centro", "Tiltshift", &slider_centro, 100, tiltshift);
    createTrackbar("Saturação", "Tiltshift", &slider_saturacao, 100, tiltshift);

    // Processamento inicial
    tiltshift(0, 0);
    
    waitKey(0);
    return 0;
}

Vídeo com Tilt-Shift

  • Este código aplica um efeito tilt-shift simples no vídeo do gato Brás Cubas, na tentaiva de criar uma ilusão de miniatura que deixa só uma faixa central nítida enquanto o resto fica desfocado e saturado. Ele processa cada frame do vídeo original misturando a imagem nítida com uma versão borrada usando uma máscara suave, depois aumenta um pouco a saturação das cores para dar aquele toque mais vibrante. O resultado final é um vídeo lado a lado mostrando a cena original e a versão modificada.
